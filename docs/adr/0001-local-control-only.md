# Keep the desktop app local-only

The Windows app will control the air conditioner only while the computer and unit share the home network. The user will use the official Daikin Smart AC app for control away from home, avoiding a second remote-control integration and its cloud-account and service dependencies in this product.

## Consequences

- The MVP needs local discovery or manual device addressing and local pairing.
- The app does not need Daikin account login or cloud authentication.
- Remote access remains available through the official mobile app.
